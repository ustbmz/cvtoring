把铃声装进 iPhone

    

      

        
macOS（Finder）

        
    
          
  1. 数据线连接 iPhone，解锁并点「信任此电脑」。
    2. 
          
  2. 打开 Finder，在左侧边栏点你的 iPhone（如 ZPhone）。
    3. 
          
  3. 新版 macOS 没有「铃声」标签，直接把下载的 .m4r 文件拖进右侧设备页面，或拖到左侧的 iPhone 图标上。
    4. 
          
  4. 等待同步进度条走完即可。
    5. 
        

      

      

        
Windows

        
    
          
  1. 安装 Apple Devices（微软商店）或 iTunes。
    2. 
          
  2. 数据线连接 iPhone，解锁并点「信任此电脑」。
    3. 
          
  3. 打开设备页面，找到 铃声 / Tones 一栏，把 .m4r 文件拖进去。
    4. 
          
  4. 点「同步」，等待完成。
    5. 
        

      

    

    

      5
      
在 iPhone 上启用：设置 → 声音与触感 → 电话铃声，在「自定义」里选刚导入的铃声。想设成某个联系人的专属铃声，可在通讯录里编辑该联系人 → 铃声。

    

    
如果列表里没出现：确认文件后缀是 .m4r（不是 .m4r.m4a）、时长不超过 40 秒；再拔线重插、解锁手机重新同步一次。
